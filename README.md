# Tamtam_Delicacies

A  modern, responsive restaurant website designed to showcase Tamtam Delicacies' menu, services, chefs and catering options.

## Project Overview

Tamtam Delicacies is a modern restaurant website designed to provide
customers with an easy way to explore the restaurant's menu, services,
chefs, and contact information online.

The website focuses on creating a warm, luxurious, welcoming, and
user-friendly experience while highlighting the restaurant's fresh
ingredients and authentic African flavors.

## Problem Statement

Tamtam Delicacies primarily relied on its physical location and social
media presence to reach customers. Customers did not have a dedicated
website where they could easily view the menu, learn about the restaurant,
explore its services, and find contact information.

This project was created to provide customers with a centralized online
platform for discovering the restaurant and its services.

## Project Objectives

- Create a professional online presence for the restaurant.
- Showcase the restaurant's menu and food offerings.
- Highlight catering and take-away services.
- Introduce the restaurant's chefs.
- Provide customers with contact and location information.
- Create a responsive experience across different screen sizes.
- Practice semantic HTML and CSS.
- Improve my understanding of responsive web design.

## Challenges Faced

During the development of this project, I encountered several challenges.

### Responsive Design

One of the challenges was ensuring that the website remained visually
appealing and functional across different screen sizes.

I had to learn how to use CSS media queries, flexible layouts, and
responsive units to adapt the design for smaller screens.

### CSS Layout

Another challenge was positioning and aligning different sections and
components correctly.

I practiced using Flexbox and CSS Grid to create more structured layouts.

### Git and GitHub

I also encountered challenges when pushing the project to GitHub and
configuring the repository for deployment.

This helped me understand Git commands, remote repositories, branches,
and GitHub Pages more effectively.
